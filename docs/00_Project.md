# TinyRedstoneForge

## Description

TinyRedstoneForge is a Forge-only implementation inspired by Tiny Redstone.

The goal is not only to recreate the original functionality but also to build a clean, extensible and well documented architecture.

## Target Version

Minecraft 1.21.6

Forge 26.1.2

## Objectives

- Multiplayer support
- Stable saves
- Expandable component API
- Fast signal engine
- Modern renderer
- Clean code

Current Milestone:

Alpha 0.1
