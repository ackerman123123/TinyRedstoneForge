# TinyRedstoneForge

TinyRedstoneForge is an open-source recreation of Tiny Redstone for **Minecraft 1.21.6** using **Forge 26.1.2**.

## Project Goals

- Recreate Tiny Redstone mechanics
- Full multiplayer support
- High performance
- Modular architecture
- Open source

## Current Progress

- Panel Engine
- Component Registry
- Lever
- Lamp
- Wire
- Placement System
- Signal Engine
- NBT Saving

## Planned

- Renderer
- Networking
- GUI
- Repeater
- Comparator
- Display
- Blueprint System
